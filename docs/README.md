## Evidence convention

- Verified fact: supported by an identifiable source.
- Observation: directly observed from a provider's public product/customer journey.
- Hypothesis: an opportunity or assumption requiring validation.
- Decision: explicitly approved project direction.
- Open question: information still required before a decision.

Research is time-sensitive. Pricing, plan features, infrastructure claims, and availability should be rechecked before commercial launch.
