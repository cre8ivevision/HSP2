# 02. Competitor Analysis

Status: Research
Last updated: 2026-09-21

## Purpose

Compare Pakistan-facing providers on publicly observable products, pricing, infrastructure signals, customer experience, and operational scope.

## Initial competitor set

- creativeON
- HosterPK
- Websouls
- HostCry
- TezHost
- SymbolHost
- Other established local providers
- Global providers serving Pakistani customers, including Hostinger

This is a research set, not a ranking.

## Comparison framework

| Dimension | What to measure |
|---|---|
| Product range | Shared, WP, business, reseller, VPS, cloud, dedicated |
| Pricing | Entry price, renewal price, billing period |
| Resources | Disk, CPU, RAM, inode/process/database limits |
| Infrastructure | Location, web server, storage, isolation, redundancy |
| Performance | CDN, caching, LiteSpeed, object cache, HTTP/3 |
| Security | SSL, malware protection, firewall, backups |
| Provisioning | Instant/manual, activation time |
| Control panel | cPanel, custom panel, Plesk, other |
| Customer portal | Billing, services, domains, tickets, invoices |
| Payments | Banks, wallets, cards, gateways, recurring billing |
| Support | Channels, hours, ticket/chat/phone, migration |
| UX | Plan discovery, checkout, onboarding, account management |
| Agency | Reseller, white-label, client management |
| Developer | SSH, Git, runtimes, databases, APIs |
